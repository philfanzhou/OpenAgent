# C# ACP Demo 验证记录

验证日期：2026-10-15（Asia/Shanghai）。环境：macOS arm64、.NET SDK 8.0.422、目标框架 net8.0。

范围为工作区新增的 [ACP Demo](../integrations/acp-dotnet-sdk/DEMO.md)，不覆盖完整 SDK 规格、平台服务或外部 ACP SDK。

## 自动验证

在仓库根目录依次执行：

```sh
dotnet build Backend/samples/acp-demo/AcpDemo.sln
dotnet test Backend/samples/acp-demo/AcpDemo.sln --no-build
```

结果：构建成功，**0 warning、0 error**；测试 **23 通过、0 失败、0 跳过**。

| 验证组 | 证据范围 |
|---|---|
| 19 个进程级用例 | 独立原始 JSON Client 连接真实 Agent 子进程；版本协商、会话、Unicode 流式输出、取消并续聊、会话忙、错误和通知无响应、int64 ID、EOF 清理 |
| 4 个传输用例 | 单字节分片/多帧/CRLF/Unicode、EOF 半帧、1 MiB 限额、取消时写完当前 JSON 帧 |

进程用例在结束时关闭 stdin，要求 Agent 五秒内干净退出，并检查退出码和 stderr；不依赖大模型或外部服务。

## 手动运行

```sh
dotnet run --no-build --project Backend/samples/acp-demo/OpenAgent.Acp.Demo -- client "你好 ACP 🥐"
dotnet run --no-build --project Backend/samples/acp-demo/OpenAgent.Acp.Demo -- client --cancel "Cancel this streaming response"
```

正常示例展示 `Echo: 你好 ACP 🥐`，最终 `Stop reason: end_turn`。取消示例在首块后发送通知，原 prompt 响应返回 `Stop reason: cancelled`。两者均正常退出。

## 证据边界

本次没有运行官网 TCK、官方 TypeScript/Python/Rust SDK 互操作、真实模型、Windows/Linux、AOT 或完整平台回归。Demo 没有实现 MCP 连接和所有稳定 v1 方法，因此本记录不构成完整 ACP 兼容认证。
