如何使用
  1. 仓库根目录运行 cd tools/deploy-wizard && npm ci && npm start（Node.js ≥ 20）。
  2. 准备已有 PostgreSQL、Redis、S3 和 IdP，填写并下载配置。
  3. 按文件路径保存后，在仓库根目录运行 scripts/deploy.sh check。准备镜像和证书后运行 scripts/deploy.sh。
仅生成配置和探测，不直接部署；不生成基础设施环境文件。部署说明：docs/operations/deployment.md。
