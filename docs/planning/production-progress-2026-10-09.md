# OpenAgent 合并功能任务管制表（2026-10-09）

本轮把上一版 **64 条具体功能任务**与用户给出的 **7 个功能方向及优先级**合并为 **68 条可认领任务**。七个方向用于组织子任务，不能以七条概览替代原有功能范围。每条任务有具体目标、验收结果、模块、优先级、工时及前序，任何人可认领。

本表保留原 64 条中的全部功能：MCP 认证由 1 条细分为 3 条（增加 2 条），备份恢复由 1 条细分为 2 条（增加 1 条），新增独立授权配置界面 1 条，合计 68 条。没有重新加入试运行签收、总体验收或空泛架构收口任务。

范围依据包括用户提供的异常、压缩、MCP认证、授权管理、数据库备份、Workflow 和审批需求，以及上一版对主干 `045c13420ba17a2601fdb73c725640318f21c82b` 的 [统一 TODO](https://github.com/philfanzhou/OpenAgent/blob/045c13420ba17a2601fdb73c725640318f21c82b/docs/planning/TODO.md) 和生产缺口评估。本轮整理任务定义和依赖，未重新运行所有功能以证明其缺口状态；认领时仍需核对实际实现和已合并工作。

工时已按当前代码中的可复用能力逐项重估：**68 条合计 654 人时**，原 2,096 人时作为历史估算保留。此次仅调整工时，未删减任务、改变目标、放宽验收标准或修改依赖。

具体交付边界：

- 异常处理分别交付异常归集、输入输出留存脱敏、执行时间线及详情查看。记录用于重建会话事实，不自动重做历史写入或外发。
- 会话压缩分别交付预算校验、摘要压缩及失败重试、历史保存续聊、超大结果存储、结果搜索和分段读取，覆盖用户指出的“摘要模型先超限、会话永久失败”问题。
- MCP认证分别交付原始及代理入口身份校验、用户委托和连接缓存隔离、凭据轮换撤销及连接失效。
- 授权管理分别交付规则保存查询、目录及调用授权、撤权及授权记录、配置界面、文件访问分享控制、业务记录及 URI 权限、数据外发限制、路由候选过滤。公共策略只计一次，各入口负责落实相同权限边界。
- 数据库备份分别交付定时备份及记录查询、指定备份恢复及进度查询。保留上一版关联文件与解密材料配套恢复范围，避免只还原数据库而业务仍不可用。
- Workflow 包含六项可复用的任务执行基础能力：任务创建、后台提交、事件订阅、暂停继续取消及重启恢复、操作去重、任务工作台；再加五项编排能力：定义及实例、步骤依赖和条件分支、并行汇合恢复、多 Agent 交接、跨 Agent 补偿。基础能力不在编排任务中重复计价。
- 风险操作审批分别交付操作拦截及审批请求、决定处理及续执行、工作台审批卡片。按用户要求优先考虑 MAF 原生审批能力，当前项目版本的实际接入方式认领时核对。

## 表格及 Issue 字段

继续保留一个工作表、11 个字段：序号、任务名称、任务模块、优先级、预计工时（小时）、任务目标、验收标准、前序任务、Issue地址、状态、负责人。不增加实际工时、日期、测试细项或实现设计列。

CSV 和 Issue JSON 使用相同字段：`number`、`title`、`module`、`priority`、`estimate_hours`、`goal`、`acceptance_criteria`、`predecessors`、`issue_url`、`status`、`assignee`。Issue 正文包括模块、优先级、工时、目标、标准及前序。验收标准描述功能行为，不另建验收任务。

当前 Issue 地址及负责人为空，状态为“待认领”；本次未创建 Issue 或实现同步。建立实际 Issue 时，以其地址作为同步身份，将表内前序序号转换为真实 Issue 依赖。建立之后固定序号，筛选或排序不重写依赖身份。既有总规划 Issue 不代填为子任务自己的地址。
