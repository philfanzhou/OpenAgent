横切约束

RunGrant 身份身份来自门禁卡，不来自模型参数
OperationId写操作必带，不自动重发 prompt
Fencing租约失效的 Worker 在写入端被拒
审批高风险动作暂停等待人工决定
审计与追踪traceId：Router → Control → Worker
依赖方向自上而下，Contracts 最底层；Architecture.Tests 锁定
